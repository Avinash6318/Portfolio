# Personal Portfolio

A modern, responsive portfolio website built with Next.js and React to showcase my projects, technical skills, education, and contact information.

## Features

- Responsive design
- Smooth animations
- About Me section
- Skills
- Education
- Featured Projects
- Contact section
- Modern UI

## Tech Stack

- Next.js
- React
- Tailwind CSS
- Motion

## Installation

```bash
git clone <repo-url>
cd portfolio
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Folder Structure

```
app/
 ├── components/
 ├── layout.js
 ├── page.js
```
